# 游戏语音出档检查工作台

Windows 本地配音交付工具：台本匹配、波形剪辑、多轨组合、男女版本管理、连续审听、响度与真峰值检查，以及批量导出。

## 下载与安装

**[下载最新 Windows 64 位安装包](https://github.com/2569723312/game-voice-workbench-releases/releases/latest)**

打开页面后，在 Assets 中下载 `GameVoiceWorkbench-版本号-Windows-x64-Setup.exe`。适用于 Windows 10/11 64 位；无需另装 Python、FFmpeg 或浏览器。

安装包尚未进行数字签名，Windows 可能提示 SmartScreen。请确认下载来源；每个版本提供 `SHA256SUMS.txt` 供核对。其他更新文件无需手动安装。

## 使用与更新

1. 新建项目，导入配音台本和录音；也可以选择不需要台本的音频剪辑工作流。
2. 连续审听并标记问题，按需剪辑、拼接、拆分和调整增益。
3. 一键审核后导出 WAV / OGG，复制文件名与时长。

0.3.7 及以后版本内置本仓库的固定更新地址。启动后静默检查；发现新版时，在首页右上角显示 **“检测到有最新版本，点此更新”**。用户自行选择下载与安装，不强制更新，不自动重启。

此前未配置更新地址的版本，需要从上面的地址手动安装 0.3.7 或更高版本一次，之后可以在软件内更新。

## 本地数据

录音、台本与存档在本机处理，不上传到此仓库。项目数据与软件独立，保存在 `%APPDATA%\GameVoiceWorkbench\data`。

升级保留存档；卸载默认保留项目数据，只有取消保留并再次确认才删除。首页可分享项目 ZIP，也可导入他人分享的存档，每次导入为独立副本。重要资料仍建议另做备份。

本仓库用于公开安装包、版本说明和更新校验文件，不存放用户录音、台本、存档或应用源码。GitHub 在不同地区的连通性可能不同，检查更新失败不影响离线使用。
